# CastraCloud Marketing Website

Standalone Next.js marketing website for CastraCloud.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Import this folder/repository into Vercel. Framework preset: Next.js. No environment variables are required.

GitHub repository:
https://github.com/Alanv0303/CastraCloud
